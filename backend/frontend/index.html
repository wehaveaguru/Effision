How It Works

Zero manual data entry or scripts required. Everything executes automatically in the background.

1
Instant AI Normalization & Enrichment

Groq LLM extracts clean titles, value propositions, technical specifications, and key features directly from raw input.

2
Dense Vector Embeddings (384-Dim)

Calculates 384-dimensional vector embeddings and indexes them in Supabase pgvector with HNSW cosine similarity.

3
Knowledge Graph Nodes & Edges

Creates Product, Brand, Category, Attribute, and Supplier graph nodes with provenance-tracked relation edges.
